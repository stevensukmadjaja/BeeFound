**BeeFound: Campus Lost-and-Found Website**

This project was developed as a group project for the Software Engineering course at Bina Nusantara University. BeeFound is a campus lost-and-found website prototype designed to help students at BINUS University Alam Sutera report and browse lost-and-found items through a centralized platform. The application was built using HTML, CSS, JavaScript, Python, Flask, and Flask-SQLAlchemy, with Figma used for interface design. It includes user registration and login, item reporting with image uploads, item browsing, report editing, comments, resolved-item status, and an admin dashboard. Through this project, our team learned how a web interface connects with backend logic and a database to manage users, item reports, and comments. We also developed a better understanding of application workflows, session-based access, and the relationship between interface design and data management. Working on BeeFound helped us strengthen our teamwork, coordinate development tasks, and translate a campus problem into a functional software prototype. The project was developed for academic and demonstration purposes.
